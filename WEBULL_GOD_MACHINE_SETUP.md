1. Log in to Webull website → Click avatar → **API Management**
2. Go to **My Application** → Submit application
3. Wait **1-2 business days** for approval
4. After approval: **Application Management** → Create app → **Generate Key**
5. Get your **App Key** and **App Secret**

#### 2. Store Secrets in Replit
```bash
# In Replit, add these secrets:
WEBULL_APP_KEY=your_app_key_here
WEBULL_APP_SECRET=your_app_secret_here
```

#### 3. Install Webull Python SDK
```bash
pip install webull-python-sdk-core

```
