## The Production Pipeline

### Phase 1: SCRIPT (3 min)

**Source:** `content/PICTORY_VIDEO_SCRIPTS.md` has 10 pre-written scripts

**If writing new scripts, follow these rules:**
- 200 words MAX for a 2-minute video (100 words/min speaking pace)
- First sentence = the hook (question, bold claim, or surprising fact)
- One concept per video. If you need two concepts, make two videos
- End with a call to action: subscribe, comment, or watch the next video
- Read it aloud before proceeding. If you'd skip any part, cut it

**Anti-Fluff Checklist:**
- [ ] Does every sentence add NEW information?
- [ ] Are there any "filler" phrases? (e.g., "In this video, I'm going to talk about...")
- [ ] Is the hook in the first 5 words?
- [ ] Can you explain the core idea in one sentence? (If not, the script is too broad)

### Phase 2: PICTORY (5 min)

1. Go to Pictory -> "Script to Video"
2. Paste your script
3. Settings:
   - Aspect ratio: 16:9 (landscape for YouTube)
   - AI Voice: Pick one voice and STICK WITH IT (brand consistency)
   - Style: Professional/clean
4. Preview all scenes
5. Remove any stock footage that doesn't match the script
6. DO NOT hit "Generate/Download" until you're satisfied
   - Drafts = free. Renders = uses minutes. Be sure before rendering

**Minutes Conservation Tips:**
- Preview in Pictory's editor (free) before rendering
- Shorter videos use fewer minutes
- If a video needs major changes after rendering, edit in CapCut instead of re-rendering in Pictory

### Phase 3: CAPCUT (10 min)

**Import:** Drag your Pictory MP4 into CapCut

**The 5-Step Polish:**

1. **HOOK (0:00-0:03):** The first 3 seconds decide everything
   - Add bold text overlay with the key question/claim
   - Consider adding a subtle zoom effect
   - NO slow intros, NO logos, NO "hey guys"

2. **TRIM:** Go scene by scene
   - Any scene that repeats information = DELETE
   - Any pause longer than 0.5 seconds = CUT
   - Generic stock footage with no purpose = DELETE
   - Target: cut 20-30% of the Pictory output

3. **PACE:** Select the entire timeline
   - Speed up to 1.1x-1.15x (sounds natural, saves time)
   - Slow down key moments to 0.9x for emphasis

4. **EFFECTS:** Add sparingly
   - Text pop-ups for key numbers (0.42, 0.9239, etc.)
   - Zoom on important visuals
   - Smooth transitions between scenes (dissolve or cut, nothing fancy)

5. **OUTRO (last 5 sec):**
   - "Subscribe for more TI Sigma discoveries"
   - End screen placeholder (20 seconds of space for YouTube end screen)

**Export Settings:**
- Resolution: 1080p
- Format: MP4
- Frame rate: 30fps

### Phase 4: TUBEBUDDY (5 min)

**Before uploading, prepare these in TubeBuddy:**

**Title Formula:**

Examples:

### Phase 5: YOUTUBE UPLOAD (5 min)

1. Upload the CapCut-polished MP4
2. Paste TubeBuddy-optimized title, description, tags
3. Set thumbnail (make in CapCut: your face + bold text + bright color)
4. Add to playlist: "TI Explained", "Trading Signals", "Consciousness Science", or "Quick Hits"
5. Schedule for peak time (TubeBuddy tells you when your audience is online)
6. Add end screen: subscribe button + next video suggestion
7. Add cards: link to related videos at key moments

### Phase 6: OPUS CLIP (2 min)

1. Copy your YouTube video URL
2. Paste into Opus Clip
3. Wait for AI to auto-detect best clips (usually 2-5 options)
4. Download top 2-3 clips (vertical 9:16 format)
5. Upload to YouTube as Shorts (same channel, separate content)
6. Optionally post to Instagram Reels / TikTok

**Opus Clip Budget:** 10 free clips/month = use on your top 3-5 videos

## Content Quality Standards

### The "Would I Watch This?" Test
Before publishing ANY video, ask:
1. Would I click on this thumbnail/title if it appeared in my feed?
2. Would I watch past the first 5 seconds?
3. Would I watch to the end?
4. Would I subscribe after watching?

If any answer is "no," fix that part before publishing.

### The 3-Second Rule
YouTube's algorithm heavily weights the first 3 seconds. If viewers click away:
- Your video gets suppressed in recommendations
- Your channel gets deprioritized
- All your SEO work is wasted

**Fix: Make the first 3 seconds the BEST part of the video.**

### Series Consistency
- Same AI voice across all videos (brand recognition)
- Same intro style (short! 2 seconds max)
- Same end screen layout
- Consistent thumbnail style (your face + bold text + color)
- Upload on a schedule (algorithm rewards consistency)
