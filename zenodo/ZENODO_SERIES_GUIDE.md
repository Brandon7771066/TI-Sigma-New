# TI Sigma — Zenodo Series Setup Guide

## The Goal
All TI Sigma papers should be discoverable by searching "TI Sigma" or "Emerick" on Zenodo,
organized into a single community that acts as the series home.

---

## Step 1: Create the Zenodo Community (do once)

1. Go to https://zenodo.org/communities/new
2. Fill in:
   - **Identifier**: ti-sigma  (becomes zenodo.org/communities/ti-sigma)
   - **Title**: TI Sigma Research Series
   - **Description**: TI Sigma is an experimental philosophy framework — Tralse Informationalism / Transcendent Intelligence — unifying consciousness, mathematics, and physics through eight primary constants {0, 1, i, √2, e, φ, π, C}. Authored by Brandon Charles Emerick. Includes formal proofs, URB paper series, provisional patents, and simulation code.
   - **Website**: (your website if any)
   - **Curation policy**: Open (or Restricted — your choice)
   - **Logo**: optional — upload a TI Sigma logo if available
3. Click Create.
4. Community URL will be: https://zenodo.org/communities/ti-sigma/

## Step 2: Fix the "No Title" Draft

The untitled draft from March 10, 2026 needs to be completed or deleted.

To complete it:
1. Go to your Zenodo uploads: https://zenodo.org/me/uploads
2. Click the "No title" draft
3. Add title, description, and resource type
4. Add it to community: ti-sigma
5. Publish

To delete it:
1. Click the draft
2. Click the red "Delete" button

Most likely this is a duplicate — check if it duplicates any already-published upload before deleting.

## Step 3: Add All Existing Records to the Community

For each of the 5 existing published records:
1. Go to the record's page
2. Click Edit (pencil icon)
3. Scroll to "Communities" field
4. Type "ti-sigma" and select it
5. Save and publish the new version (it will be v2 for version-controlled records)

Alternatively, from the Community admin page:
1. Go to https://zenodo.org/communities/ti-sigma/curate
2. You can search for your own records by DOI and add them from there

Use this template for every new upload:

**Title**: [Paper title exactly as in the .md file header]
**Authors**: Emerick, Brandon Charles
**Affiliation**: TI Sigma / BlissGene Therapeutics (independent)
**Description**: [Abstract from the paper — first paragraph]
**Keywords**: TI Sigma, Tralse Informationalism, Transcendent Intelligence, LCC, GILE, Myrion Resolution, [paper-specific keywords]
**Journal/Series name**: TI Sigma Research Series
**License**: Creative Commons Attribution 4.0 (CC BY 4.0) — allows sharing with credit
**Community**: ti-sigma (always add this)
**Related identifiers**: Link to prior papers in the series using their Zenodo DOIs

- "TI Sigma" in the title OR in the keywords
