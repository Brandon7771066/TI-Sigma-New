# TI Sigma Calibration Registry Semantic Versioning Rules

## Version Format: MAJOR.MINOR.PATCH (e.g. 1.0.0)

### Version Increment Rules:
- **MAJOR**: Construct definition or schema breaking compatibility (e.g. altering label count or coordinate ranges).
- **MINOR**: Addition of new calibration data or newly validated domain profile.
- **PATCH**: Metadata, typo, or provenance correction that does not alter numerical values.
