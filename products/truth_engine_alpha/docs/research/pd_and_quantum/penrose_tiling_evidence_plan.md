# Penrose Tiling Evidence Plan

Current status: UNVERIFIED_HISTORICAL_RESULT

## Recovery Checklist

- exact task
- input/output data
- comparison models
- success criteria
- claimed noncomputational signature
- TI Sigma intervention
- randomization
- controls
- replications

## Interpretation Ladder

1. pattern-recognition advantage
2. geometric reasoning advantage
3. algorithmic novelty
4. failure of tested baselines
5. evidence against specific computational models
6. noncomputationality claim

Only the first four are currently operationally testable.

## Experimental Controls

- preregistered task definitions
- fixed evaluation script
- blinded scoring where possible
- repeated seeds and perturbation tests

## Commercial Policy

Do not present noncomputability claims before controlled evidence reaches replication standards.
