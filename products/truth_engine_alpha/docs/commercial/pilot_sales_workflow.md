# Pilot Sales Workflow

## 1. Inquiry
Client sends interest note or outreach reply.

## 2. Scope confirmation
Confirm one answer, up to 20 claims, domain, and deadline.

## 3. Payment
Use Stripe payment link or PayPal invoice before analysis starts.

## 4. Client submits material
Receive AI answer, prompt, citations/links, and intended use.

## 5. Engine analysis
Run Truth Engine Alpha and produce structured artifact package.

## 6. Human review
Reviewer verifies citation classifications and corrected conclusion framing.

## 7. Delivery
Send final audit package and concise executive briefing.

## 8. Feedback
Collect client feedback on clarity, usefulness, and turnaround.

## 9. Testimonial request
Request optional short testimonial if client is satisfied.

## 10. Case-study permission
Request explicit permission for anonymized case-study use.

## Notes
No payment processing is built into Truth Engine Alpha in this phase.
