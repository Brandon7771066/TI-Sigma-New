# Zoo Webcam Links for Animal Synchrony Study

## Primary Zoo Pair: Elephants

### Smithsonian National Zoo (Washington DC)
- **Webcam URL**: https://nationalzoo.si.edu/webcams/elephants
- **All Webcams**: https://nationalzoo.si.edu/webcams
- **Species**: Asian Elephants (Spike, Bozie, Swarna, Maharani, Trong Nhi, Nhi Linh)
- **Hours**: 24/7 (best viewing during daylight, ~7am-7pm EST)
- **Features**: Multiple camera angles, indoor Elephant Community Center
- **Current Status**: TEMPORARILY OFFLINE (as of Jan 23, 2025) - elephant birth expected
- **Notes**: Free, no registration required. Cannot embed/restream (Smithsonian copyright)

### San Diego Zoo Safari Park (California)
- **Webcam URL**: https://sdzsafaripark.org/cams/elephant-cam
- **All Webcams**: https://sdzsafaripark.org/live-cameras
- **Alternative**: https://sdzwildlifeexplorers.org/videos/livecam/elephant-cam
- **Species**: African Elephants (8 elephants including Umngani, Swazi, Mkhaya, Zuli)
- **Hours**: 24/7 (best viewing during daylight, ~7am-7pm PST)
- **Current Status**: TEMPORARILY UNAVAILABLE - construction on Denny Sanford Elephant Valley
- **Notes**: Free, no registration required

**Distance Between Zoos**: ~3,700 km (2,300 miles)
**Time Zone Difference**: 3 hours (EST vs PST)

### IMPORTANT: Current Availability Issue
Both primary elephant webcams are temporarily offline:
- Smithsonian: Due to elephant birth window

**Workaround Options**:
1. Use alternative species (lions, pandas, apes) until elephant cams return

## Technical Notes

### Screen Recording Setup
1. Use OBS Studio (free) to record webcam
2. Set 30-second interval timer
3. Record timestamp overlay

### Recommended Recording Settings
- Resolution: 720p minimum
- Frame rate: 15fps (sufficient for behavior coding)
- Format: MP4

### Timestamp Synchronization
- Use UTC for all recordings
- Sync computer clock to NTP server before recording
- Note timezone offset for each zoo
