# Canonicalization Workflow

Status Label: NEW_CANONICAL_DRAFT

Use this fixed sequence:

Source received
-> Source hashed
-> Source logged
-> Relevant passages indexed
-> Conflicts identified
-> Historical and current versions separated
-> User-approved resolution recorded
-> Canonical document updated
-> Canonical change committed

## Explicit prohibitions

- Do not perform silent reconciliation.
- Do not overwrite historical definitions.
- Do not treat later wording as automatically superior.
- Do not use prior AI summaries as original evidence.
- Do not invent missing corpus items or hashes.
