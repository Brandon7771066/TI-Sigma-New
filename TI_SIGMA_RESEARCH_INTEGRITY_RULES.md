# TI Sigma Research Integrity Rules

Human-authored working standard. Recorded here so later work can follow the same text. The application of these rules to the current repository is an AI-assisted note in `TI_SIGMA_EXPERIMENT_LEDGER.md` section 21 and `TI_SIGMA_RESEARCH_GAPS.md` section G14. That application is not itself a result.

## Evidence discipline

Never convert:

- a hypothesis into a result
- a simulation into empirical validation
- a correlation into causation
- an LLM-generated claim into evidence
- a literature association into TI Sigma confirmation
- a proxy measurement into a direct measurement

Every result must be classified as:

- VERIFIED
- REPRODUCIBLE
- REPORTED
- UNREPRODUCED
- INCONSISTENT
- PLANNED
- HYPOTHESIS

## Reproducibility

Whenever possible record:

- dataset
- dataset version/hash
- source
- preprocessing
- random seed
- model
- hyperparameters
- null model
- baseline
- sample size
- statistical test
- effect size
- confidence interval
- p-value where appropriate
- exact script
- exact commit

## Model competition

TI Sigma-specific models must be compared against:

1. simple baselines
2. conventional scientific baselines
3. capacity-matched generic models
4. randomized/null models

A TI Sigma model does not win merely because it produces an interesting pattern.

## Negative results

Preserve negative results.

Never delete an experiment merely because it failed.

Never reinterpret a failed prediction as confirmation without explicitly changing the hypothesis.

## Elegance

Goodness must remain operationally defined through the 8Cs.

Elegance must not silently absorb:

- HEM
- correspondence
- pragmatic success
- Intuition
- Love
- Consistency

If an Elegance feature overlaps another construct, flag the overlap.

## Graph/Crystal

Treat TIC and TIG as distinct but complementary PDs.

Do not merge their roles merely because they are mathematically related.

Canonical versions must be frozen before biological prediction.

## Thresholds

Keep these conceptually distinct until experimentally resolved:

- sqrt(2)-1
- 0.93 Radiant Threshold
- T
- phi
- Born-shaped value
- Emerick Constant

Do not collapse them into one constant.

## Biology

Never claim a zebrafish FAAH-OUT ortholog, Jo Cameron phenotype, therapeutic effect, or human translational equivalence without explicit evidence.

## AI assistance

Record AI-generated suggestions separately from human-authored hypotheses and independently verified results.

The purpose is reproducibility, not concealment.
