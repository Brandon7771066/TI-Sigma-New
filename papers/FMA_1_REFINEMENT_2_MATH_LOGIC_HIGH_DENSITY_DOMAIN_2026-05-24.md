## 2. "2+2=5" Worked Example (Brandon's Canonical Case)

**Claim:** 2+2=5

**F-status:** TRUE (the claim is false). 2+2=4 is provable from Peano axioms.

**MI-status:** TRUE (the claim is inconceivable-under-mental-actualization per refinement #4 + Pass-65 DT canonical heuristic). One cannot form a stable mental model of "2+2=5 while 2, 4, 5, +, = retain their standard meanings" — the attempt produces conceptual collapse.

**Counterfactual test (refinement #1):** Can we imagine W' where 2+2=5 is true AND the standard arithmetic counterexamples (every actual calculation of 2+2 yielding 4) still exist?

**Answer: NO.** If 2+2=5 in W', the entire arithmetic chain restructures: either 2, 4, 5, +, or = have different meanings (in which case "2+2=5" is no longer the SAME claim being evaluated), OR the standard counterexamples disappear (because 2+2 just doesn't yield 4 in W'). There is no possible-world where 2+2=5 is true AND the standard 2+2=4 calculations still happen with the standard symbol meanings.

**Therefore: 2+2=5 is FMA-1.** F + MI structurally aligned via counterfactual-impossibility.

## 3. Why Math/Logic Are High-Density FMA-1 Domains

**Structural reason:** Math/logic claims are evaluated against **necessary truths** (Peano axioms + classical logical inference + definitions). False math/logic claims at the elementary level violate these necessary truths. Violation of necessary truth = inconceivable-under-mental-actualization (you cannot form a stable mental model where 2+2 yields 5 with standard symbol meanings — the model fails to compose). The falsehood IS the inconceivability.

**Contrast with empirical-contingent domains:** In empirical-contingent domains (physics, biology, history), false claims violate contingent facts. False claims about contingent facts are NOT inconceivable — you can mentally model phlogiston, geocentrism, or spontaneous generation as a coherent theory; you just discover they're empirically false. Counterfactual W' worlds where phlogiston is true are conceivable. Hence empirical-contingent false claims are plain-F, not FMA-1.

**Math/logic = necessary-truth domain → false claims = necessary-falsehoods → necessary-falsehoods = inconceivable-under-actualization → FMA-1 applies.**

**Empirical-contingent = contingent-truth domain → false claims = contingent-falsehoods → contingent-falsehoods = conceivable-but-counterfactually-wrong → plain-F applies.**
