### [THE BSD PARITY THEOREM — 2:30-5:30]

The Birch and Swinnerton-Dyer conjecture is about elliptic curves — equations of the form y² = x³ + ax + b over the rational numbers.

For each such curve E, you can count rational solutions (points). The rank of E — call it r — is the "dimension" of this set of solutions.

BSD says: the rank equals the order of vanishing of a certain function L(E,s) at s=1. The function L(E,s) is defined by an infinite product that converges only when Re(s) > 3/2. Yet BSD says its behavior at s=1 — which is OUTSIDE the region of convergence — encodes the exact algebraic rank.

This is the miracle BSD is trying to explain.

Now here's what we proved.

Every elliptic curve has a "root number" ε_E — either +1 or −1. It comes from the functional equation:

Λ(E, s) = ε_E · Λ(E, 2 − s)

where Λ is the completed L-function. This equation is symmetric about s = 1.

At s = 1 specifically: Λ(E, 1) = ε_E · Λ(E, 2−1) = ε_E · Λ(E, 1).

If ε_E = −1: then Λ(E,1) = −Λ(E,1). So 2·Λ(E,1) = 0. So Λ(E,1) = 0. So L(E,1) = 0.

This is the **parity vanishing theorem**: if the root number is −1, then L(E,1) = 0 unconditionally. No BSD assumption required.

We proved this in Lean 4. The proof runs: derive the functional equation at s=1, substitute ε_E = −1, get L = −L, so 2L = 0, so L = 0. The key step — showing that 2 ≠ 0 in ℂ — uses `two_ne_zero` from Mathlib.

This is a real theorem. It was known to experts, but it had never been written in Lean before.

---

### [WHY THE FULL CONJECTURE REMAINS OPEN — 5:30-7:00]

So why can't we finish it?

Two reasons.

First, the **forward direction** (rank ≥ 1 → L(E,1) = 0) is proved for ranks 0 and 1 — by Gross-Zagier (1986) and Kolyvagin (1988). For rank ≥ 2, it's completely open. We'd need to extend Kolyvagin's Euler system technology to higher rank curves — a problem that has resisted attack for 38 years.

Second, the **converse** (L(E,1) = 0 → rank ≥ 1) is open for ALL ranks. This is the harder direction — it requires extracting a rational point of infinite order from analytic data. Nobody knows how to do this in general.

These are exactly the axioms in our Lean file, labelled [OPEN]. The parity theorem sits above the gap — provable without BSD — and everything else sits below it, requiring the open conjectures.

When a proposition is Tralse — genuinely indeterminate — Myrion Resolution asks: what can we determine?

**Second MR (quality check):** Was the first resolution correct? Complete? Was the right frame applied? The second MR is meta-cognitive — it examines the reasoning process, not just the conclusion.

**Third MR and above (Meta-Truths):** When the third resolution substantially contradicts the second — or the second contradicts the first — that contradiction is called a Meta-Truth. Not an error: a refinement. The Permissibility Distribution is converging toward its true value through successive approximations.

The process terminates either by convergence — successive MRs confirm rather than contradict — or by deliberate cessation: you decide that the current PD value is good enough to act on.

**Dissolution MTs:**

**Scope-Shift MTs:**
- *Escalate* — the stakes are higher than the prior frame assumed. The question needs bigger context.

**Integration MTs (highest level):**
