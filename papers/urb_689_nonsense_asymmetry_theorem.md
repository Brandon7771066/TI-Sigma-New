## 1. The Combinatorial Argument: Nonsense Space >> Sense Space

For any domain D with N base concepts, the number of well-formed statements is combinatorially large. The number of **truth-correct** (GILE-G consistent) statements is a strict subset determined by the actual structure of reality — the constraints imposed by what IS.

Consider the ratio:

```
|Nonsense Space| / |Sense Space| → ∞ as N → ∞
```

**Why:** Truth-correct statements must satisfy structural constraints — they must track actual relationships between things. These constraints are the minority of all possible relationships. For any N objects, there are N² possible binary relationships but only a small fraction obtain in reality. The ratio of possible-to-actual grows without bound.

**Analogy:** Consider N-bit binary strings. The number of strings that encode valid, compiling, correct programs is exponentially smaller than all possible N-bit strings. Most strings are noise. The set of meaningful programs is a vanishingly small subset of the total string space — and it grows more slowly than total string space as N grows.

**TI Sigma formal statement:**

Let Σ = total statement space, Σ_T = truth-correct (GILE-G consistent) subspace.

```
Theorem: |Σ_T| / |Σ| → 0 as |Σ| → ∞.
Corollary: Σ \ Σ_T (the nonsense space) dominates Σ asymptotically.
Corollary: A random statement drawn from Σ is almost certainly DT.
```

The nonsense asymmetry is not a matter of degree — it is a structural feature of the relationship between possibility space and truth space.

## 2. The Kolmogorov Argument: Truth Is Compressible, Nonsense Is Not

From algorithmic information theory (Kolmogorov complexity):

- **Truth-correct statements** reflect underlying regularities — patterns, laws, structures. Because they encode structure, they are **compressible**. A true statement about physics can be derived from a shorter underlying law.
- **DT statements** reflect no underlying regularity — they are randomly structured relative to reality. They are **incompressible**. There is no shorter description of a random falsehood than the falsehood itself.

By the Kolmogorov incompressibility argument: **most strings (of any sufficient length) are incompressible.** Therefore most statements are DT. The truth-correct statements are precisely the compressible ones — the minority.

This means: **truth has lower Kolmogorov complexity than nonsense on average.** But paradoxically, *finding* the compressed representation of truth requires enormous cognitive work (MR), even though the truth itself is shorter. The MR search cost is high even when the target is small.

## 3. Truth Acquisition Is Harder by Default

Given the dominance of nonsense space, a consciousness that simply accepts its HEM signals (all real, all potent, per URB #688) without performing GILE-G correction will:

1. **Encounter mostly DT content** — because DT dominates the statement space
2. **Register all of it as existentially real** — because HEM(DT) > 0 always
3. **Default to labeling it True** — because applying the label "True" requires zero MR work; applying the label "Tralse" requires at least one MR step

The path of least resistance is:
```
HEM signal received → registered as real → labeled True (no GILE check)
```

The MR path is:
```
HEM signal received → registered as real → GILE-G test applied → correct label assigned
```

The MR path costs cognitive resources: attention, time, working memory, willingness to update beliefs, tolerance of uncertainty during the MR process. These are finite and scarce in any biological consciousness.

**Formal statement:**

Let C_DT = cognitive cost of accepting a DT statement = near zero (just label True)  
Let C_MR = cognitive cost of performing one MR step = positive and non-trivial

```
C_DT << C_MR, always.
```

Therefore DT is the cognitively dominant equilibrium. Not because consciousness is broken — because it is following the accurate signal (HEM is real) and applying the cheaper operation (labeling True without GILE check).
