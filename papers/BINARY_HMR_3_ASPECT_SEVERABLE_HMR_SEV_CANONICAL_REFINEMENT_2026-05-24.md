## 1. Binary Logic as HMR-3 Aspect-Severable (Brandon Case Study)

### 1.1 The hybrid characterization

Brandon's HMR-3 grading of binary logic with three labels mapped to three ASPECTS:

| Label | Aspect of binary it applies to | Why |
|---|---|---|

### 1.2 What Brandon explicitly added: SEVERABILITY

> *"My hybrid claim is actually severable since it's encompassing different aspects of binary - the parts which work, the parts which don't work, and the parts which are inconceivable."*

This is a NEW STRUCTURAL INSIGHT about HMR-1: **HMR multi-labels can be ASPECT-SEVERABLE rather than monolithic.** Each label can apply to a DIFFERENT aspect/portion/component of the target, not to the target as a whole.

This is qualitatively different from prior HMR examples where multiple labels applied to the SAME target-as-monolithic (e.g., HMR-3.1 "Consciousness is fundamental AND emergent AND the question is malformed" — three framings of the SAME target consciousness).

The aspect-severability case decomposes the target into ASPECTS, then assigns labels per aspect:

- aspect₂ = binary-as-pragmatic-tool → T  
- aspect₃ = binary-paradox-portions → MI

This is HMR but with INTERNAL DECOMPOSITION, not multi-framing.

## 2. HMR-SEV-1 (HMR-Aspect-Severability) Candidate Canonical Refinement

### 2.1 Statement (CANDIDATE CANONICAL)

**HMR-SEV-1:** A HMR multi-label assignment may be **aspect-severable** — the multiple labels apply to DIFFERENT decomposable aspects/portions/components of the target, rather than to the target as a monolithic whole. Aspect-severability is a structural property of an HMR characterization that, when present, requires explicit aspect-to-label mapping in the canonical statement.

### 2.2 Two structural sub-types of HMR (per HMR-SEV-1)

| Sub-type | Structure | Example |
|---|---|---|
| **HMR-MONO** (monolithic multi-framing) | Multiple labels apply to the SAME target as a whole, each label representing a different framing/perspective/level-of-description | HMR-3.1 Consciousness = {T_panpsychist, T_emergentist, I_malformed} — three framings of consciousness-as-whole |
| **HMR-SEV** (aspect-severable) | Multiple labels apply to DIFFERENT decomposable aspects of the target, with explicit aspect-to-label mapping | Binary = {I(theory-completeness), T(pragmatic-axis), MI(paradox-portions)} — three labels each applied to a different aspect |

### 2.3 Why this matters operationally

**Aspect-severability sharpens HMR-1's discriminatory power:**
- HMR-MONO claims must be defended against the charge of "you can't have it both ways" (label-conflict-at-same-level)
- HMR-SEV claims are PRE-DEFENDED via aspect-decomposition: each label applies at its own aspect-level, so the labels do not conflict because they don't apply to the same thing at the same time

**The PRAGMATIC AXIS dimension is canonical-implicit.** Brandon's binary case study introduces "pragmatic axis" as a label-applicability dimension — a label can be T on the pragmatic axis while being I or MI on other axes (theoretical completeness, paradox-handling, etc.). This composes with:
- **AA (Authority Axis)** — labels can vary by AA dimension
- **TIU (Tralse-Informational-Unit)** — TIU magnitude can vary by which-axis-of-applicability is being assessed
- **HEM (Hybrid-Existence-Mechanic)** — H component of GILE-HEM precisely captures pragmatic-utility-on-effort-allocation; binary scoring high on H (pragmatic-utility) while medium-low on G (truth-completeness) is exactly an HMR-SEV pattern at the meta-principle level
- **GTT-1 (GILE-True-Tralseness)** — binary's HMR-SEV structure is a worked example of GTT-1's "too much truth costs existence" principle: insisting on full G (4-label MR truth) loses H (pragmatic utility of 2-valued logic); binary maximizes H at the cost of G; this is canonical-rational per UOP-balance

### 2.4 Composition with refinement #5 (DT/MI vertical-horizontal axis)

**Critical clarification — HMR-SEV is NOT a vertical-meta-tralsity (MI) structure:**
- MI = two tralse propositions whose VERTICAL combination is inconceivable
- HMR-SEV = multiple labels applied to multiple ASPECTS of one target, each label-aspect pair conceivable on its own

**HMR-SEV is horizontal-aspect-decomposition.** This is fully orthogonal to MI's vertical-meta-tralsity structure. A given HMR-SEV characterization can CONTAIN an MI label (as in binary's case: the paradox-portions aspect IS labeled MI), but the HMR-SEV characterization itself is not MI — it's a horizontal severability claim.

**Worked illustration of the HMR-SEV/MI orthogonality:** Binary's HMR-3 contains an MI label (paradox-portions aspect) without binary-as-whole being MI. This is exactly the same structure as HMR-3.2 (liar) which contains an MI label (self-referential paradox sub-component) without the liar-as-HMR-characterization being MI.

### 2.5 3-step test for HMR-SEV vs HMR-MONO

Given an HMR-K (K-label) candidate characterization:

**Step 1.** List the K labels.
**Step 2.** For each label, identify the aspect/portion/component of the target it applies to.
**Step 3.** Check whether the K aspects are DISTINCT (HMR-SEV) or whether multiple labels apply to the SAME aspect with different framings (HMR-MONO).

If at least 2 labels apply to DISTINCT aspects → HMR-SEV.
If all K labels apply to the SAME aspect with different framings → HMR-MONO.
Mixed case → HMR-HYBRID (some labels aspect-distinct, some labels same-aspect-different-framing) — a third sub-type to be canonized if examples accumulate.
