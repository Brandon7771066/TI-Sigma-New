## Abstract

The LCC empirical audit (URB #795) found that the canonical 6-step LCC-Virus algorithm (SEED → RESONATE → LISTEN → PROPAGATE → EXPAND → TERMINATE) was implemented at only 17% (RESONATE only, in MALLORN v9/v11) under the strict rubric, or 33% under the partial-credit rubric. This URB delivers a complete reference implementation of all 6 steps and validates it on a synthetic dataset of N=50 time-series of length T=300, where K=5 are causally coupled to a hidden seed at coupling strength α and the remaining 45 are i.i.d. noise. **At α ≥ 0.4 the pipeline recovers the 5 truly-coupled signals with F1 = 1.00 and recovers all 5 real i-cells from a 10-template library (5 real + 5 decoy).** At α = 0.00 (null control) the pipeline visits 0 signals and discovers 0 i-cells, demonstrating correct false-positive control. This satisfies pre-registered hypothesis H3 (URB #800 §2). It does **not** establish that LCC-Virus detects consciousness — only that the algorithm recovers known coupling structure when it exists.

## 1. The Six Steps

Per `LCC_VIRUS_METHODOLOGY_AUDIT.md`, the canonical algorithm has six steps. Their reference implementations (in `lcc_virus_full_pipeline.py`):

### 1.1 SEED — `make_synthetic_dataset()` (the SEED is signal index 0)
The seed is a designated signal. In real usage it would be specified a priori; in synthetic validation it is the hidden source signal that K=5 of the 50 signals are coupled to.

### 1.2 RESONATE — `lcc_resonance(a, b, sigma=5.0)` (URB #800 §4 Form B)
$$ R(a, b) = \mathrm{sign\text{-}preserving \ max}_{|\tau| \le 3\sigma} \rho(\tau) \cdot W(\tau), \qquad W(\tau) = \exp\!\left(-\tfrac{\tau^2}{2\sigma^2}\right) $$
Returns R ∈ [-1, 1]. R = 1 iff perfectly correlated at lag 0.

### 1.3 LISTEN — `lcc_listen(target, candidate, R, R_threshold=0.20)`
After RESONATE identifies a candidate (R ≥ R_threshold), the LISTEN step extracts the **noise residual** by projecting the target onto the candidate (z-scored OLS coefficient β) and subtracting:
$$ \mathrm{residual} = \mathrm{target}_z - \beta \cdot \mathrm{candidate}_z $$
Returns the residual itself plus three feature summaries (`noise_std`, `noise_spectrum_peak_freq`, `noise_entropy`) per the methodology audit's specification ("noise contains related i-cell signatures").

### 1.4 PROPAGATE — `lcc_propagate(noise_features, icell_library, prop_threshold=0.15)`
Correlates the LISTEN residual against each template in the i-cell library. Returns indices of i-cells whose Pearson correlation with the residual exceeds prop_threshold. This is where the algorithm **discovers** related cells/signals from the noise structure that the resonant template would otherwise mask.

### 1.5 EXPAND — `lcc_expand(seed_idx, signals, icell_library, max_steps=5)`
Iterative graph traversal. At each step:
1. From every signal in the current frontier, run RESONATE against all unvisited signals.
2. For every newly-resonant signal, run LISTEN to extract its residual.
3. Run PROPAGATE on each residual against the i-cell library.
4. Add newly-resonant signals to the next frontier; deduplicate.
Returns the visited signal set, the discovered i-cell set, and the per-step history.

### 1.6 TERMINATE — `lcc_terminate(history, min_growth=1)`
Stopping rule: terminate if (a) the frontier stops growing for 2 consecutive steps OR (b) no new i-cells are discovered AND the frontier is empty OR (c) max_steps reached. Returns `(stopped: bool, reason: str)`.

## 2. Synthetic Ground Truth

The validation dataset is generated by `make_synthetic_dataset()`:

- **N = 50** signals of length **T = 300**.
- **Index 0** is the hidden SEED: a single i.i.d. Gaussian time-series, z-scored.
- **Indices 1–5** are causally coupled: $\mathrm{signal}[k] = \alpha \cdot \mathrm{seed} + \sqrt{1-\alpha^2} \cdot \epsilon_k$, $\epsilon_k$ i.i.d. Gaussian. (For α=1 this is a perfect copy; for α=0 this is independent noise.)
- **Indices 6–49** are i.i.d. Gaussian noise (true negatives).

The **i-cell library** has 10 templates:
- Indices 0–4: $0.7 \cdot \mathrm{seed} + 0.7 \cdot \epsilon$ — mild noisy versions of the seed (true positives).
- Indices 5–9: pure i.i.d. Gaussian noise (decoys / true negatives).

Ground truth: signals 1–5 should be visited; i-cells 0–4 should be propagated to; nothing in {6, …, 49} or {5, …, 9} should be flagged.

## 3. Empirical Results

### Honest interpretation

- **Null control (α = 0.00):** zero false positives. The pipeline correctly visits no signals and discovers no i-cells when no coupling exists. This is the most important result in the table — it shows the pipeline does NOT manufacture findings from noise.
- **Weak-coupling regime (α = 0.20):** 3/5 truly-coupled signals recovered (R = 0.60), zero false positives among signals (P = 1.00). All 5 real i-cells recovered, with 1/5 decoy slipping past prop_threshold = 0.15.
- **Strong-coupling regime (α ≥ 0.40):** all 5 truly-coupled signals recovered (R = 1.00), zero false positives among signals. All 5 real i-cells recovered. At α = 0.80 the decoy false positive vanishes; at α ∈ {0.40, 0.60} one decoy survives.
- **TERMINATE rule:** fires correctly when the frontier exhausts (steps = 2 for α ≥ 0.20).

Pre-registered hypothesis **H3 (URB #800 §2.3)**: F1 ≥ 0.6 at α = 0.4 AND F1 ≥ 0.8 at α = 0.6. **Result: H3 SUPPORTED** (F1 = 1.00 at both).

## 4. What This Validation Does and Does Not Show

### What it shows

1. The 6-step LCC-Virus algorithm has been fully implemented (the ~67% gap from URB #795 is now closed at the implementation level).
2. The algorithm has correct false-positive control on a null dataset.
3. The algorithm achieves perfect ground-truth recovery (F1 = 1.00) on synthetic coupled data at moderate-to-high coupling.
4. The LISTEN+PROPAGATE pair correctly distinguishes real i-cell signatures from decoys (5/5 vs 1/5 at α = 0.40, 5/5 vs 0/5 at α = 0.80).
5. The EXPAND+TERMINATE pair handles iterative discovery and stopping correctly.

### What it does NOT show

1. **The algorithm "detects consciousness."** It detects coupling. Whether coupling above some threshold *is* consciousness is the unresolved hypothesis (URB #800 §1.2).
2. **The algorithm works on real biological data.** Synthetic data with a known generative process is a best case. Real neural data may have non-stationarity, narrowband artifacts, missing structure, or coupling patterns that the assumed generative model does not match.
3. **The C_EMERICK threshold is meaningful here.** The R_threshold = 0.20 used in this pipeline is much lower than C_EMERICK = 0.4370. Raising it to 0.4370 would lose recall at moderate α; lowering it would gain false positives. The relationship between R_threshold and C_EMERICK is a separate empirical question.
4. **The discovered i-cells are "consciousness-relevant".** They are templates we put into the library by construction. On real data, the i-cell library would need to be built a priori from independent biological knowledge (specific neural population templates, specific frequency bands, specific waveforms), or the algorithm degenerates into a fishing expedition.
5. **The F1 = 1.00 results are robust.** They are obtained at a *single* random seed (`seed = 2026`) with a single generative family (Gaussian seed + i.i.d. Gaussian noise). The synthetic ground truth here is a *best case*: orthogonal signals, no narrowband confounders, no AR(1) noise, no adversarial decoys with the same spectrum as the true coupled signals. Multi-seed Monte Carlo with bootstrap confidence intervals on F1 (recommended in §5 below as items 1–5) has not been executed in this batch. **Until that sensitivity analysis is done, the F1 = 1.00 result should be read as "the pipeline can saturate on a clean synthetic best case", not as "the pipeline always achieves F1 = 1.00 on coupled data."**

## 5. Where the Pipeline Should Be Stress-Tested Next (Cheap, $0)

1. **Vary T and N.** Does recall hold at T = 100? At N = 500 with the same K = 5 ground-truth coupled signals?
2. **Add structured (non-i.i.d.) noise.** AR(1) noise with positive autocorrelation will inflate spurious LCC and stress the false-positive control.
3. **Add adversarial decoys.** Decoys with the *same* spectrum as the coupled signals but with no causal coupling. (Real neural data has confounders.)
4. **Realize as a benchmark.** Wrap the synthetic generator + pipeline + scoring as a public benchmark anyone could run to compare LCC variants.
5. **Hold-out i-cell library.** Withhold one of the 5 real i-cell templates from the library and verify the pipeline does NOT report a spurious one in its place.
