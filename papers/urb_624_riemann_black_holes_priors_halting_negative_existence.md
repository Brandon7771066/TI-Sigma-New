### 4.2 The Grothendieck Group Construction

The integers ℤ are constructed from the natural numbers ℕ via the **Grothendieck group** (also called group completion):

```
ℤ = {[(a, b)] : a, b ∈ ℕ} / ~
where (a, b) ~ (a', b') iff a + b' = a' + b
```

Each integer is an equivalence class of pairs of natural numbers:
- "5" = [(5, 0)] = [(6, 1)] = [(7, 2)] = ... (all pairs where first exceeds second by 5)
- "−3" = [(0, 3)] = [(1, 4)] = [(2, 5)] = ... (all pairs where second exceeds first by 3)
- "0" = [(0, 0)] = [(1, 1)] = [(2, 2)] = ...

**Key observation:** In this construction, "−3" is not intrinsically negative. It is a pair (0, 3) representing "3 minus 0 in the other order." The negativity is **relational and order-sensitive** — it arises from the choice of which natural number in the pair is "on top." If you invert the convention (second minus first instead of first minus second), all the signs flip. **The distinction between positive and negative integers is a choice of orientation — a choice of threshold.**
