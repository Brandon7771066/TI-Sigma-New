## 6. The Mandelbrot Connection

The Mandelbrot set — the most famous fractal in mathematics — is defined by the iteration z_{n+1} = z_n² + c, where z and c are complex numbers. The boundary of the Mandelbrot set separates points that iterate to infinity (outside) from points that remain bounded (inside).

**TI Sigma interpretation:** Let z_n = the LCC state of a system at iteration n, and c = the external driving condition. Then:
- **Inside the Mandelbrot set (bounded iteration):** The system is in a stable coherent state — LCC remains above C_EMERICK indefinitely
- **Outside the Mandelbrot set (diverging to infinity):** The system is in a runaway state — LCC grows without bound in one direction (mania, extreme market trend) before collapse
- **The boundary (Julia set):** The system is precisely at the Matthew boundary — the most complex, information-rich, and self-similar state

The richest structure in the Mandelbrot set occurs at the main cardioid boundary, where the fractal complexity is greatest. This is the mathematical analogue of the TI Sigma claim that the most interesting and richest behavior occurs at the Matthew boundary — near C_EMERICK — not in the fully coherent (inside) or fully incoherent (outside) regions.
