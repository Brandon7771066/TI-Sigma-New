## 2. ETM-1 v2 vocal addendum — VPS (Vocal Performance Signature) added as 9th feature

**Brandon pointer (verbatim):** *"make sure you capture the vocal aspects with the GVB music if possible!"*

The Phase-1 ETM-1 (8 features) under-specified vocal-music sources. Gaither Vocal Band is 4-part-male-quartet vocal-quartet music; vocal performance carries a substantial fraction of its transformational-trigger signal beyond the 8 structural-feature substrate. **VPS is added as the 9th ETM-1 feature.** Per Pass-65 refinement-precedent (MR-IDC-1 refined MR Truth Labels without count-increment), **VPS does NOT increment the canonical principle count** — it is ETM-1's first refinement (analogous to MR Truth Labels canonical refinements 1-8).

### 2.1 VPS composite spec (6 sub-features)

| Sub-feature | Description | Audio-extraction |
|---|---|---|
| **VSF** | **Vocal-stack Spectral Fusion** — formant alignment + just-intonation tightness within multi-voice stack | LPC formant detection per voice + cross-channel coherence + spectral-flatness inversion within voice-bands |
| **LTS** | **Lead-voice Tessitura+Strain** — head-voice usage at peaks, controlled-vibrato density, upper-quartile-pitch frequency | Pitch tracker (YIN / pYIN) → upper-quartile relative to typical lead-vocal range + vibrato-rate autocorrelation |
| **VCM** | **Vocal-Color Modulation across arc** — chest→head→falsetto transitions, vowel-modification ("ah" widening at climaxes) | Spectral-centroid trajectory segmented + per-segment vowel-detection via formant pattern matching |
| **GMP** | **Grit/Melisma at Peaks** — intentional vocal-grit texture + melismatic ornamentation at structural-arc peaks | Spectral-kurtosis + pitch-trajectory melisma-density at energy-peaks |
| **TEI** | **Tag-Ending Intensification** — repeated final phrase 2-4× at progressively higher intensity/register | Final-third-segment RMS + pitch-mean comparison to mid-piece + structural-segmentation repetition detection |
| **CRA** | **Call-and-Response Architecture** — antiphonal / congregational entry pattern | Voice-activity-detection alternation pattern + diarization |

**Aggregate VPS = mean(VSF, LTS, VCM, GMP, TEI, CRA) normalized to [0, 1].**

### 2.2 Instrumental-equivalent VPS for non-vocal sources

For instrumental music (PMD-Sky), VPS-instrumental maps the same 6 sub-features onto solo-instrument and ensemble structure:

| Vocal sub-feature | Instrumental analog |
|---|---|
| VSF (stack fusion) | section-blend (string-section homogeneity, woodwind doubling) |
| LTS (lead tessitura/strain) | solo-instrument upper-range usage + controlled-vibrato (string-portamento, brass-flutter, piano-pedal-resonance) |
| VCM (color modulation) | timbral-modulation across arc (orchestration density changes, instrument-family entry sequence) |
| GMP (grit/melisma) | ornamental flourishes at peaks (trills, glissandi, cadenzas) |
| TEI (tag-ending) | coda / reprise / motif-restatement intensification |
| CRA (call-and-response) | antiphonal section-trading (string ↔ woodwind ↔ brass) |
