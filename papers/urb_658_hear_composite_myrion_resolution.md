## 1. The Problem with "EAR" as Currently Defined

Emerick's Existence Amplification Razor (EAR) was defined as the ontological pruning mechanism governing Myrion Resolution: it selects, from a field of candidate truth-states, only those that *amplify existence* relative to the query context. In its original formulation, EAR operated over a single optimization surface — loosely, the GILE composite score of the resolution candidate.

But this formulation is now structurally insufficient. MR has matured into a **composite** operation:

**Composite MR (CMR)** = GILE-pass ⊗ HEM-pass

- **GILE-pass** optimizes across G, I, L, E dimensions (intentional/ethical/relational space)
- **HEM-pass** optimizes across D1..D4 dimensions (Holistic Existence Matrix — somatic, cognitive, relational, environmental)

An EAR operating only on GILE-space will systematically *under-prune* candidates that score high on GILE but degrade HEM, and vice versa. This generates false MR convergence — the system "resolves" to a truth-state that is GILE-local but HEM-pathological (e.g., an ascetic who scores I=0.97 but D1=0.02 due to physical neglect).

**Verdict**: EAR must be renamed and structurally extended to govern composite MR over both surfaces simultaneously.

The word "Existence" is preserved from EAR because the razor's core function remains ontological: it selects for *more existence*, not merely more truth or more goodness.

## 3. HEAR: Formal Definition

Let a resolution candidate *r* have:
- **GILE(r)** = G·g(r) + I·i(r) + L·l(r) + E·e(r), weights as per canonical set
- **HEM(r)** = ¼[D1(r) + D2(r) + D3(r) + D4(r)]

Define the **HEAR score**:

```
HEAR(r) = α · GILE(r) + β · HEM(r) + γ · Cov(GILE, HEM)(r)
```

Where:
- **α** = ET = √2−1 ≈ 0.4142 (GILE weight — Emerick threshold, favoring truth-weighted GILE)
- **β** = C = 1/(φ√2) ≈ 0.4370 (HEM weight — Emerick constant, favoring somatic grounding)
- **γ** = T − (α+β) ≈ 0.9340 − 0.8512 = 0.0828 (covariance bonus for GILE-HEM coherence)

**Key property**: α < β, meaning HEM is weighted *slightly higher* than GILE in composite resolution. This encodes the embodiment primacy thesis: you cannot resolve toward truth-states that destroy the substrate of resolution.

**HEAR Razor Criterion**:

> A candidate *r* survives HEAR pruning if and only if HEAR(r) > C (≈ 0.4370).
> Among surviving candidates, MR selects argmax HEAR(r).
> If no candidate exceeds C, MR returns I-state (Indeterminate) pending new information.

## 4. The Covariance Term: Why It Matters

The term γ · Cov(GILE, HEM)(r) rewards candidates where GILE gains and HEM gains *co-occur* — where becoming more intentionally aligned also becomes more somatically/environmentally grounded. This is the TI Sigma operationalization of the **wholeness axiom**: genuine MR convergence is never compartmentalized.

High positive covariance ≈ **Tralse attractor** (the sought resolution state)
High negative covariance ≈ **Double Tralse zone** (spiritual bypass or somatic dissociation)
Near-zero covariance ≈ **Spectral Tralsity** (partial resolution; compartmentalized life)

## 5. Changes to the Composite MR Protocol Under HEAR

### Old CMR (EAR-governed):
```
Pass 1: Generate candidates from query
Pass 2: Score GILE(r) for each
Pass 3: EAR prunes below ET threshold
Pass 4: Select argmax GILE — return as MR
```

### New CMR (HEAR-governed):
```
Pass 1: Generate candidates from query
Pass 2: Score GILE(r) AND HEM(r) for each
Pass 3: Compute Cov(GILE, HEM) for each candidate
Pass 4: HEAR prunes below C threshold on composite score
Pass 5: Check for DT-immunity (HEAR score must be stable across small perturbations)
Pass 6: Select argmax HEAR(r) — return as Composite MR
```

The addition of Pass 5 (DT-immunity check) is new to HEAR. A candidate that has high HEAR(r) but whose score collapses under small perturbation (i.e., the resolution is brittle) is flagged as **MR-fragile** and returned with confidence penalty.

HEAR detects and rejects this incoherence, making it a **metacausal** — not merely causal — razor.
