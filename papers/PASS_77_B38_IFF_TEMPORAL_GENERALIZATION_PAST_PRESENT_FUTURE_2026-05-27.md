## §0. Executive Summary

B37 introduced IFF for *indeterminate future events*: the mind assigns a high imaginary-axis placeholder for lack of a real component to latch onto. Brandon now extends the scope: **the same imaginary-placeholder mechanism applies to past and present cases too** — wherever there is "no real component to latch onto," regardless of tense.

This yields a **temporal triad** of one mechanism:

| Tense | Operation | Why no real component | Resolution trigger |
|---|---|---|---|
| **Future** | **Foresight** (prospection) | event not yet *actualized* | actualization (time passes) |
| **Past** | **Hindsight / retrodiction** (retrospection) | event actualized but *inaccessible/unrecovered* | recovery (evidence, memory retrieval) |
| **Present** | **Insight / interpretation** (construal) | event actual but *ambiguous/uninterpreted* | interpretation (construal settles) |

In all three, the agent's *representation* carries z ≈ 0 + bi (high imaginary placeholder, low/absent real component); upon the relevant resolution trigger, z → a + 0i (real value acquired). The mechanism is tense-neutral; only the *reason* a real component is missing, and the *trigger* that resolves it, differ by tense.

The generalization **preserves the B37 Tier-2/Tier-3 boundary** (genuine N/A — category errors — still get *no* placeholder, in any tense) and **strengthens IFF** by recruiting the well-established past↔future symmetry of mental time travel (§5). The "IFF = iff" name is retained per Brandon; "Future Foresight" is now read as the *exemplar* tense, not the only one.

## §1. The Extension Stated

> **IFF Temporal Generalization (B38, extends IFF B37):**
> The imaginary-placeholder mechanism of IFF is *tense-neutral*. Whenever an agent represents a truth-apt event for which it currently has *no accessible real truth-value to latch onto* — whether because the event is (a) future and unactualized, (b) past and unrecovered, or (c) present and uninterpreted — the agent assigns a high imaginary component as a placeholder on the PD-imaginary axis. The placeholder resolves into a real component upon the tense-appropriate resolution trigger: **actualization** (future), **recovery** (past), or **interpretation** (present).

Crucially, this is a claim about the **agent's representation**, not about the event's ontology (see §4).

## §2. The Temporal Triad in Detail

### §2.1 Future — Foresight (original IFF, B37)
"Will it rain tomorrow?" The event has no real value yet because it has not actualized. The mind anticipates it with an imaginary placeholder (prospection). Resolves to real when tomorrow arrives.

### §2.2 Past — Hindsight / Retrodiction
"Did Caesar scratch his nose on the morning of the Ides?" The event *did* acquire a real truth-value (ontologically determinate), but the agent has *no epistemic access* to it. The mind reconstructs/imagines it with an imaginary placeholder (retrospection). Resolves to real only upon *recovery* — a historical record, a recovered memory, decisive evidence. Many past events never resolve in practice (lost to history) → the placeholder persists *epistemically*, though the event is *ontologically* settled. (This persistence is **not** MI/Tier-2′: it is resolvable-*in-principle*, merely not-recovered-*in-practice* — an epistemic limitation, not a self-defeating inconceivability.)

### §2.3 Present — Insight / Interpretation
"Is this ambiguous figure a duck or a rabbit?" / "Is this present situation an insult or a joke?" The event is actual and present, but its *interpretation* is open. The mind holds competing construals with an imaginary placeholder until interpretation settles. Resolves to real upon *construal/decision*. (Connects to ambiguous-figure perception, binocular rivalry, and real-time social-cue interpretation.)

### §2.4 The unifying schema
In every tense: **representational vacuum on the real axis ⇒ imaginary placeholder ⇒ resolution-trigger ⇒ real value.** The triad is one mechanism with three entry conditions and three exit triggers.

## §3. Resolution-Trigger Generalization

B37 stated only the future trigger (actualization). The generalization makes the trigger tense-relative:

- **Future → actualization:** the event happens; reality supplies the real value.
- **Past → recovery:** evidence/memory supplies the (already-existing) real value to the agent.
- **Present → interpretation:** construal/decision selects among live readings, collapsing to a real value.

This is the same imaginary→real "collapse" dynamic (B37 §5), now with three trigger-types. The active-inference reading (B37 §5.1) generalizes cleanly: the generative model runs *forward* (prediction/prospection) and *backward* (postdiction/retrodiction) and *laterally* (present disambiguation), with non-observed states carried as imaginary placeholders in each direction.

## §4. Epistemic vs. Ontological — a Strengthening Clarification

The past case forces a clarification that *strengthens* IFF overall:

**IFF is a hypothesis about the agent's representation, not about the event's ontological truth-status.**

- A past event is *ontologically* determinate (it happened or it didn't — a real value exists in the world).
- But the agent's *representation* of it, absent access, carries an imaginary placeholder.
- The placeholder lives in the *model*, standing in for an inaccessible real value.

This was implicit in B37 ("IFF is about cognitive representation") but the past case makes it explicit and sharp: **the imaginary component indexes the agent's epistemic relation to the real value, not the real value's existence.** This blocks a naive objection ("but the past is fixed, so there's nothing imaginary about it") — IFF never claimed the *event* was imaginary, only the agent's *placeholder* for an inaccessible value.

This also cleanly separates the three "no real component" reasons:
- **Future:** real value does not *yet exist* (ontological-not-yet).
- **Past:** real value *exists but is inaccessible* (epistemic-not-recovered).
- **Present:** real value *is being constituted by interpretation* (constructive-not-yet-settled).

Three different metaphysical situations, one representational response.

## §5. Empirical Anchor: Mental Time Travel (the past↔future symmetry)

The temporal generalization is not merely elegant — it aligns with one of the more robust findings in cognitive neuroscience (to my knowledge; specific-citation verification pending per corpus #69 honesty convention):

- **Constructive memory (Bartlett; Schacter):** remembering the past is *reconstructive*, not a playback of a recording — the mind *imagines* the past, often with error and confabulation. This is exactly an imaginary-placeholder operation.
- **Mental time travel / episodic future thinking (Tulving; Schacter & Addis "constructive episodic simulation"):** remembering the past and imagining the future recruit *overlapping* neural machinery — the default-mode network and hippocampus support *both*. The brain uses one simulation engine pointed in two temporal directions.
- **Prediction & postdiction (active inference / predictive processing):** the generative model represents non-observed states (future *or* hidden-past *or* ambiguous-present) as inferences, updated by evidence.

**IFF's temporal generalization predicts exactly this symmetry:** the same imaginary-placeholder mechanism should underlie foresight and hindsight (and present interpretation). The convergence with mental-time-travel findings is a meaningful prior in IFF's favor and materially strengthens the eventual Option-A ratification case (B37 §9).

## §6. The Tier-2 / Tier-3 Boundary Survives (genuine N/A still gets no placeholder)

A critical #69 check: does extending IFF to past/present *leak* into genuine N/A (Tier-3, NAO-1)? **No.** The discriminator is unchanged: *is there something truth-apt to anticipate, recover, or interpret?*

- Future "will it rain": truth-apt → Tier-2 imaginary. ✓
- Past "did Caesar scratch his nose": truth-apt, actualized, inaccessible → Tier-2 imaginary. ✓
- Present "is this figure a duck or rabbit": truth-apt, interpretable → Tier-2 imaginary. ✓
- Category error "is the number 7 jealous" (any tense): **not** truth-apt → Tier-3 off-grid, **no placeholder**. ✗

Genuine N/A is off-grid in *every* tense because non-truth-aptness is tense-invariant: "was 7 jealous?", "is 7 jealous?", "will 7 be jealous?" are all equally not-truth-apt. The temporal generalization expands Tier-2 across tenses without touching the Tier-2/Tier-3 line. This is the precise meaning of Brandon's "past and present *interpretations possible with* N/A": where an *interpretation is possible* (truth-apt, latch-able via placeholder), it is Tier-2; where none is possible (genuine N/A), it stays Tier-3.

## §8. Pre-Registered Falsifiers (temporal-generalization-specific)

The B37 falsifiers (IFF-F1..F4) carry. New ones for the generalization:

- **IFF-TG-F1 (past-future dissociation):** if past-event representation (retrodiction) is shown to use a *categorically different* mechanism from future-event representation — no shared simulation machinery, dissociable under lesion/load — the temporal generalization is refuted (though future-only IFF could survive). *Current status: pre-supported against refutation by mental-time-travel findings (§5); honestly noted as a prior, not a closure.*
- **IFF-TG-F2 (present uses real axis):** if present-ambiguity representation demonstrably uses real-axis scalar values (not imaginary placeholders) with no qualitative placeholder signature, the present-extension is refuted.
- **IFF-TG-F3 (tense-asymmetric Tier leak):** if genuine N/A (category errors) receive imaginary placeholders in past/present tense but not future (or vice versa), the Tier-2/Tier-3 boundary is tense-dependent and §6 fails.
- **IFF-TG-F4 (no-collapse for past):** if recovered past events do *not* show placeholder→real resolution (the imaginary component persists *after* decisive evidence arrives), the resolution-trigger account fails for the past tense.

All OPEN; IFF-TG-F1 noted as prior-supported but not closed.
