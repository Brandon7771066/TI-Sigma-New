**The strongest candidate is the chirality-doubling factor 2 itself** (exact match within experimental scatter) or **2π/e ≈ 2.31** (5% match, structurally meaningful).

Argue that the framework's brain-FHS structure is real but **does not correspond to a fundamental-physics quantity**. Brain scaling exponent ≈ 2.2 might be set entirely by neuroscience-internal dynamics (cross-frequency coupling depth, network topology, etc.) without any deeper framework connection.

This is the **most conservative option** and would **partially weaken URB #705**'s biology-physics bridge claim, downgrading it from "structural confirmation" to "interesting parallel."

## 8. Lessons Learned

1. **Canonical centroids matter**. Brand-new computations using independently-generated noise gave one wrong answer (1.39); canonical literature centroids give a more honest answer (2.2). Always start with canonical literature values when testing a claim.
2. **Honest disconfirmation strengthens the framework**. Reporting the brain-side disconfirmation lets the framework adjust to a more accurate position (brain ↔ chirality-doubling) instead of holding to a refuted position (brain ↔ lepton mass ratio).
3. **Multi-part claims should be tested in pieces**. URB #705 had a confirmed part (lepton scaling) and a disconfirmed part (brain-lepton bridge). Recognizing this structure prevents wholesale framework rejection over a partial failure.
4. **Predictive content is preserved through revision**. The revised brain-chirality-doubling reading is still framework-anchored and still falsifiable. The framework loses no predictive content; it gains better calibration.
