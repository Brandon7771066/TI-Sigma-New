## 2. Mechanism I — MR1 Universal Attractor

**Definition 2.1:** A mathematical claim P is *MR1-universal* if and only if P passes the Myrion Resolution gate in every possible context simultaneously.

Most claims are MR1-local: "the economy is growing" (True in some periods, False in others, Tralse at turning points). Mathematical claims about complex systems are MR1-regional: "nonlinear dynamics produce emergence" (True for high-complexity systems, weakly true for simple ones, inapplicable to some domains).

But arithmetic uniformity is MR1-universal: "2+2=4" passes MR1 in every possible context — physical, mathematical, logical, empirical, cosmological. No domain exists in which 2+2≠4 would be coherent. The LCC of "2+2=4" is 1.0 — maximum coherence, zero variance across contexts.

**Theorem 2.1 (MR1 Attractor):** Mathematical uniformity is the fixed point of the MR1 operator applied across all possible contexts. Uniform mathematical truths are those Tralse claims which resolve to True under maximum-context MR1 application.

**Proof sketch:** Apply MR1 iteratively, expanding the context set at each step. For non-uniform claims, at some finite context expansion, MR1 will return Tralse or False (the claim fails in some context). For uniform claims, MR1 returns True at every context expansion step. The MR1 universal attractors are exactly the set of claims that survive this infinite-context limit — the crystallized residue.

**Corollary 2.2:** The reason arithmetic is more uniform than analysis, which is more uniform than topology, which is more uniform than quantum mechanics, is that each step involves claims with smaller MR1 context-universality. Arithmetic claims survive the most context expansions; quantum mechanical claims survive the fewest.
