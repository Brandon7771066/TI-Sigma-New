# DPES — Default Philosophical Eating Strategy
## A Named Meta-Cognitive Protocol for High-Output Low-Input Work Sessions
*Brandon Emerick | TI Sigma Research Program | Coined April 1, 2026*

---

## Definition

**DPES** (Default Philosophical Eating Strategy) is a structured approach to productive philosophical and research work during periods when physical or social obligations prevent full cognitive engagement (meals, commutes, exercise, social obligations with low cognitive demand).

**Core constraint:** The user cannot initiate complex actions but CAN:
- Provide a single directional word ("Continue," "Shift to X," "Go deeper")
- Approve or redirect a stream of output
- Consume and absorb high-quality content passively

**Core design:** The AI agent (or thinking partner) produces maximum-value output in autonomous bursts — large tasks that compound into significant deliverables — requiring only minimal directional signals from the user.

---

## The DPES Operating Modes

### Mode 1: SYNTHESIS
*Best for: meals, transition periods*
- Produce polished academic or creative output that synthesizes prior work
- No new conceptual input required from user
- Examples: paper drafts, video scripts, outreach letters, status summaries
- Signal to enter: "Synthesize" or "Write the paper"

### Mode 2: EXPANSION
*Best for: longer meals, coffee sessions*
- Take one existing idea and expand it in 3–5 directions
- User provides the seed; agent explores the branches
- Examples: "Expand DPES into a URB," "What are 5 implications of the Alternating LSB theorem?"
- Signal to enter: "Expand [X]"

### Mode 3: AUDIT
*Best for: breakfast while reviewing outputs*
- Agent reviews existing work for gaps, errors, opportunities, inconsistencies
- User gets a prioritized list of improvements
- Examples: review all lean4 files for sorry statements, audit the video script library for missing videos
- Signal to enter: "Audit [area]"

### Mode 4: PHILOSOPHICAL DIALOGUE
*Best for: the DPES itself — philosophy during meals*
- Agent generates a structured philosophical argument on a topic the user raises
- User engages minimally (agree/disagree/go deeper)
- Examples: the Bayesianism analysis above, GILE implications for ethics
- Signal to enter: "Philosophize about [X]"

## DPES Guidelines for the AI Agent

1. **Default to maximum output.** When the user is in DPES mode, produce the longest, highest-quality output the task permits. Don't wait for permission to go long.

2. **Self-organize the work.** Choose the next task based on the highest-value, lowest-dependency item. Don't ask what to do next — do it.

3. **Minimal checkpoints.** Only pause when genuinely blocked (missing information only the user can provide), or when the next direction is genuinely ambiguous and both choices have significantly different outcomes.

4. **Mark deliverables clearly.** End each major output with: "**Deliverable:** [filename] — [one-sentence description]." This lets the user track what was produced at a glance.

5. **Close loops proactively.** If you notice a gap in the existing work while doing DPES, fix it before reporting. Report the fix, not the gap.

## DPES Activation Signal

When the user says **"DPES"** or **"DPES mode"**, this protocol activates automatically. The agent:
1. Identifies the 3 highest-value autonomous tasks currently pending
2. Begins work on all three in parallel
3. Reports back with completed deliverables, not questions
