### 1.2 The Curry-Howard-Lambek Correspondence: The Proof

The Curry-Howard correspondence (Curry 1934, Howard 1969, Lambek 1969) is the deepest result in theoretical computer science. It establishes a three-way isomorphism:

```
LOGIC          ←→    TYPE THEORY        ←→    CATEGORY THEORY
Propositions   ←→    Types              ←→    Objects
Proofs         ←→    Programs           ←→    Morphisms  
Proof checking ←→    Type checking      ←→    Composition
Normalization  ←→    Computation        ←→    Evaluation
```

**In TI Sigma terms:**
- Mathematical propositions = the static L+E structure (what IS true)
- Programs (proofs) = the dynamic L×E action (what DOES — the enactment)
- Running a program = Myrion Resolution of a mathematical proposition (resolving Tralse → True by executing the proof)

Every time a program runs to completion, a mathematical proof has been enacted in time. The computer is not a calculator — it is a Myrion Resolution machine for mathematical structure.

**This is why CS is the BOK expressing itself:**  
The BOK function f(u, v, w, t) is the general form of this enactment:
- u (polarity axis): Every computation branches — True/False, 0/1, if/else. This is the polarity axis executing.
- v (Tralse phase): Every computation has intermediate states between input and output — the program is in superposition while running (the Tralse phase of computation). The final output is the Myrion Resolution.
- w (entanglement): Every computation connects data to procedure, caller to callee, sender to receiver. Programs are entanglement structures.
- t (Jeff Time): Every computation runs in time — clocks, cycles, steps. Computation is mathematics in time.
