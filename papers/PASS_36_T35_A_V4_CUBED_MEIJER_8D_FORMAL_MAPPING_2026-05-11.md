## §2 — Group-theoretic facts (rigorous, not metaphorical)

V₄ = C₂ × C₂ = ⟨a, b | a² = b² = (ab)² = e⟩.
- Order: 4
- Elements: {e, a, b, ab}
- Independent generators: 2 (a and b)
- Order-2 elements (involutions, including identity? — by standard convention NO, involution = element of order exactly 2): {a, b, ab} = 3 involutions
- Irreducible representations: 4, all 1-dimensional (V₄ is abelian); the character table is the 4×4 Hadamard matrix H₂ ⊗ H₂.

V₄³ = V₄ × V₄ × V₄.
- Order: 4³ = 64
- Independent generators: 6 (two per V₄ factor: {a₁, b₁, a₂, b₂, a₃, b₃})
- Order-2 elements: count of (g₁, g₂, g₃) with each gᵢ ∈ {e, a, b, ab} and at least one gᵢ ≠ e and (gᵢ)² = e for all i. Since every element of V₄ is order 1 or 2, every non-identity element of V₄³ is order 2. So **involution count = 64 − 1 = 63**, NOT 12. The Pass-35 architect note ("12 = order-2 element count") was itself imprecise; the Pass-36 #69 honesty correction below restates.
- Irreducible representations: 4³ = 64, all 1-dimensional; character table is H₂^⊗⁶ = H_{64} (the 64×64 Hadamard matrix). This is the canonical "V₄³ ↔ Hadamard³" Pass-31 D2-HYBRID identity.
