## 0. LinkedIn API — honest reality check (read first)

**LinkedIn does not allow programmatic profile editing for regular users.** The official LinkedIn Marketing API and Sales Navigator API exist but are restricted to:
- Approved enterprise partners (e.g., Workday for HR integrations)
- Sales / marketing analytics access (not profile-write access)
- OAuth scopes for *posting* on behalf of the user — but **not editing** headline, about, experience, skills, or featured sections

The unofficial scraping/automation route (e.g., the `linkedin-api` Python library, Selenium automation, browser-extension auto-fillers) **violates LinkedIn's Terms of Service** and routinely triggers:
- Temporary account restrictions
- Permanent account bans
- Loss of connections and recruiter visibility — exactly the resource you need most right now

**Recommended workflow:** Paste the copy from §1–§7 below into the LinkedIn UI manually. Estimated time to update entire profile: 25–40 minutes. This is the safe path that preserves your account standing during an active job search.
