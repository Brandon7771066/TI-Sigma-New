# UOP proof-strategy & Bayes reconciliation

## UOP cannot be "proven by building off the FEP"
- **Trilemma** (load-bearing): if `UOP ⊢ RH/NS`, then either (1) UOP provable in ZFC ⇒ its proof CONTAINS RH+NS ⇒ at-least-as-hard (commonality concentrates difficulty, doesn't reduce it); (2) UOP independent of ZFC ⇒ RH-from-UOP is conditional FOREVER ⇒ fails the Clay criterion; or (3) UOP inconsistent ⇒ false. No 4th branch. Only (1) "solves" anything and (1) = the hard math itself.
- **FEP is NOT proven like Bayes.** Only the FEP *kernel* (variational bound / ELBO, `F ≥ −log P(o)` via KL≥0) is a theorem — and that kernel IS Bayesian and too narrow to be a universal optimization law. The grand FEP claim ("everything with a Markov blanket minimizes free energy") is *contested*, not proven (Aguilera 2021; Biehl/Pollock/Kanai 2021; Bruineberg 2022; Colombo & Wright 2021). So "UOP = broader FEP" INHERITS the gap.
- **Two fallacies to never repeat:** "generalize an unproven claim ⇏ proven"; and "more complete ⇏ more correct" (completeness/correctness are independent — GR earned correctness by independent derivation + novel confirmed predictions, NOT by extending Newton).
- **Only real RH route = Hilbert–Pólya** (self-adjoint operator ⇒ real spectrum ⇒ zeros on line; Berry–Keating, Montgomery–Odlyzko). UOP is heuristic motivation, NOT the operator. NS analogue = make the energy-infimum a Leray–Hopf theorem, not an axiom.
- **Lean scaffold caveat:** `BeingTheorem.lean`/`MirrorPairing.lean` ASSERT the bridge via `axiom universal_bridge_theorem` (= RH restated) / `axiom euler_forcing` / `axiom UOP_existence_claim` ⇒ `riemann_hypothesis_from_being` is assume-RH→derive-RH (petitio principii). Lean confirmed the IMPLICATIONS + trivial lemmas, NOT the premises. Honest line: "derivations verified, load-bearing premise assumed" — NOT "proofs confirmed."
