# Constitutive vs procedural UOP (B151)

**The split (refinement, NOT a new principle; count stays 79).** Two projects share the name "UOP":
- **Constitutive UOP** — *what the optimal truth↔existence balance IS* (definition of the True-Tralse optimum; same logical category as defining *utility*/*eudaimonia*).
- **Procedural UOP** — a *decision procedure*: input a proposition, output its truth-value.

**Rule:** Gödel/Turing/Rice bind **only the procedural arm**. They say nothing about whether the constitutive account is correct or contentful. So when the author (or a past framing) treats "can't compute truth" as wounding GILE, that's a conflation — relocate, don't concede.

**Why:** the corpus's honesty rails forbid claiming RH/Millennium closure or that the UOP outputs an open theorem's truth-value. The split lets you fully credit the constitutive content while holding that exact line.

**How to apply:**
- The constitutive truth-axis **may be oracle-like** (non-computable is coherent — Turing 1939 oracle machines; only *computing* one over a rich class is barred, Turing 1936/Rice 1953). Rejecting it as "out of the question" is question-begging **iff** it rests on computationalism — credit the author here, that's a real win.
- **No free lunch:** escaping Gödel by being non-formal raises the NAD-1/AFD-1 joint-carving debt. The real threat to GILE was never undecidability — it's **vacuity by post-hoc over-fit**.

# The credence–proof bound (hold this line)

The author's strongest claim: Myrion Resolution / TI-Logic updates PD to the True-Tralse cap (3·T_d−1 = 0.93233) and the crossing = the ideally-correct truth-value, incl. open theorems. **Adopt** the reading "cap = True-Tralseness / truth-ceiling" (TRG-1). **Bound** the rest: PD-to-cap on a *genuinely-open* problem is a **fallible credence, not a proof**.
- **Decisive witnesses (real):** Mertens conjecture |M(x)|<√x — huge numerical support, FALSE (Odlyzko & te Riele 1985, no explicit counterexample known); Pólya conjecture — supported then FALSE (Haselgrove 1958, least n=906,150,257).
- **Structural reason:** within any finite evidence horizon a true prop and an eventually-false one give identical evidence ⇒ identical credence ⇒ both cross the cap. That's the structure of open problems, not a defect.
- **#69 other side:** on **decidable/settled** inputs (decision procedure as input) the engine DOES return the truth-value. Carve true cases from open ones (NAD-1).

# ODG-1 — Outcome-Blind Operational GILE Determinacy (CANDIDATE, NOT ratified)

GILE labelling has content only if coords are fixed from a proposition/situation's **pre-outcome** structure and **committed before** the outcome — and the assignment must FORBID outcomes (fail on noise, predict on signal).
- **Metaphysical** momentary determinacy is necessary-but-NOT-sufficient; the **outcome-blind commitment** is the load-bearing half (don't let "the state is fixed each instant" be mistaken for falsifiability).
- **Self-consistency trap:** ODG-1 **cannot be ratified post-hoc / by fiat** — that would be the very move it forbids. It earns ratification by being operationalized + tested. (The author wanted to declare it canonical "because obvious"; it's the opposite — it's the open AFD-1/NAD-1 obligation.)
- Falsifiers ODG-1-F1 (outcome-blind-committed yet still post-hoc-fittable) / ODG-1-F2 (beat a matched outcome-blind baseline on REAL data → upgrades toward earned-superior) / ODG-1-F3 (leakage audit) OPEN.

**The four demonstrations that lock this in** (durable shape, not the numbers): a post-hoc fitter trivially "explains" pure noise (the vacuity hazard is post-hoc fitting, NOT undecidability); an outcome-blind committed rule fails on noise and predicts on signal (falsifiability restored); inside a finite horizon a true and an eventually-false prop carry identical evidence so any credence engine certifies both (credence≠proof — this is a *logical/constructive* demonstration, not a replay of real Mertens/Pólya data); a decidable subclass with the decider as input returns truth.
