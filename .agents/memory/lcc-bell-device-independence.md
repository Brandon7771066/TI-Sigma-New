# LCC Bell/CHSH device-independence (DI) route

**Context:** B166 proved observational-only LCC proof-by-contradiction is UNSOUND (a common cause with an unmeasured component passes every observational guardrail). The corollary named the only correlation-only escape: the **device-independent Bell regime** — a loophole-free CHSH `2√2>2` certifies (Fine 1982) that NO local-hidden/common-cause model exists, WITHOUT measuring every hidden Z. This is the corpus's own "no global joint measure" (Fine/CHSH) machinery. The user believes quantum effects underlie LCC, so DI is the natural place to test closure.

**Rule:** For a BIOLOGICAL two-brain substrate the DI route is UNREACHABLE on known physics — resolve LCC-PROOF-F3(b) NEGATIVE, keep the Bell tie as a flagged STRUCTURAL RESONANCE (not a derivation), never claim a quantum mechanism for LCC.

**Why (three textbook bounds, all deterministic, no hardware):**
- **Locality loophole:** setting-choice + readout on each side must finish within `d/c` (~3.34 ns over 1 m) to be space-like separated; neural events take ~1 ms ⇒ ~3×10⁵ too slow. Loophole cannot be closed with neural readouts.
- **Decoherence:** Tegmark (2000, Phys Rev E 61:4194) neural decoherence ~1e-13..1e-20 s vs ~1e-3 s per neural step ⇒ ≥10 (up to ≥17) orders too fast; no shared coherence survives one step.
- **Monogamy:** CHSH monogamy (Coffman-Kundu-Wootters 2000; Toner-Verstraete 2006) `S_AB²+S_AC²≤8` ⇒ if A maximally violates with B (2√2), max S_AC=0. A full-brain NETWORK of pairwise Bell violations is barred; only one maximal partner (matches the older `quantum-connectome-mood-amplifier` note "monogamy kills full-brain pair-Bell").

**How to apply:** F3(a) (a NON-neural engineered substrate in a genuine DI regime) stays open ONLY in the abstract — this analysis does not exclude it, but no such substrate exists or is claimed. Never run/fabricate quantum hardware; the honest verdict is #69 both ways (in-principle closure for an engineered substrate, ruled out for the wet/warm/slow/~1m-separated brain). A real loophole-free Bell test needs locality + detection + freedom-of-choice loopholes closed simultaneously (Hensen 2015).
