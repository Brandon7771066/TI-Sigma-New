# Tralse staircase + binary→TI emergence

Durable decisions for how TI-Logic-vs-binary must be argued (sources: B52/BSI-1 staircase + urb_606 non-approximability). Applies whenever writing/editing the binary-vs-TI case.

## Two DIFFERENT √2 arguments — never conflate
- **i-Completeness "two routes to √2"** (ch02): √2 reached via ordinary diagonal AND via i-rotation ⇒ hint that real↔imaginary are one tralse structure.
- **Tralse staircase / BSI-1** (ch01): axis-aligned staircase approximating the unit diagonal has length **2 ∀n, never √2** (arc-length discontinuity: limit-of-lengths ≠ length-of-limit) ⇒ irreducible ~41% overhead ⇒ binary "tries but fails" to reach the genuine middle efficiently.
- Both live on the unit-square diagonal; a ch02 paragraph explicitly keeps them apart.

## Honest non-approximability framing (do NOT overclaim)
- **Do NOT assert "1s/0s can't incorporate the imaginary axis / can't represent i."** FALSE — computers compute a+bi routinely (FFTs, sims).
- **Why:** the user (Brandon) himself supplied the correct reading — "a computer computes with i" is **evidence FOR emergence**, not for a bit natively containing i; reading it as "bit contains i" merely *assumes* complex numbers are natively binary (begs the question).
- **The genuine hard wall is quantum contextuality**, not "representing i": classical/binary CHSH ≤ **2** vs quantum **2√2≈2.83**; Fine (1982) = no single classical joint distribution covers those correlations. Theorem, not an efficiency gap. (Already in ch05/ch14.)

## Emergence levels-synthesis (reconciles urb_606 vs RIM)
Three true statements, no contradiction:
1. **Component level:** a bit can't natively BE TI/imaginary; binary-as-direct-approximation **tries and fails** (BSI-1). urb_606's "tries but fails" stance stays correct (user-confirmed).
2. **Whole-system level:** TI logic + complex arithmetic **genuinely emerge** (RIM = related-instated mechanism; ch14/ch17 tralsebit) — real instantiation, not outside description.
3. **Reconciliation:** emergence does NOT *rescue* binary as the native language of reality (urb_606); it presses binary into hosting a non-binary structure. Different levels ⇒ no contradiction.

**Why this matters:** BSI-1 is candidate (not ratified) — count stays 80. The staircase math is a theorem but the truth-value mapping is #69 analogy (backed by B50's 0.23-bit stuck FDE), not proof.

## Formal-theorem home (ch16)
When formalizing these in the math chapter, TWO theorems, and keep the honesty tiers distinct:
- **Theorem 1 (Staircase / L¹-vs-L² overhead)** = the framework's OWN genuine elementary theorem (general (a,b): length=a+b ∀n; uniform convergence; arc-length discontinuity; overhead ratio ∈[1,√2], max √2 at a=b by Cauchy–Schwarz). Lean-formalizable; shelve it with φ²=φ+1.
- **Theorem 2 (classical wall)** = IMPORTED, NOT ours: Bell/CHSH |S|≤2, Fine 1982 (holds iff a single joint distribution exists), Tsirelson |S|≤2√2. Always attribute; framework contributes only the *reading*.
- **Non-negotiable rail:** every such theorem gets a "what it proves and what it does NOT (#69)" callout — the geometry/physics is proved/imported-solid, the truth-value reading (axes=T/F, diagonal=Indeterminate; contextuality=tralseness) stays **interpretation, not corollary**.
