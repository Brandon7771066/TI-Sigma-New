---
name: Gödel incompleteness ≠ contradiction (honesty rail)
description: When writing the Theory-of-Contradictions / self-reference material, never claim Gödel proved arithmetic is contradictory.
---

When porting the **Theory of Contradictions** (URB #509) self-reference argument
into prose, keep three things distinct:

- **Russell's paradox** (naive set theory) and the **Liar paradox** (unrestricted
  language) ARE genuine outright contradictions.
- **Gödel's incompleteness** is NOT. It exhibits a *limit*: a consistent
  sufficiently-strong system harbors truths it cannot prove — a **discrepancy**
  between truth and provability, not an inconsistency in arithmetic.

**Why:** an architect review flagged "Gödel proved it [contradiction] for
arithmetic … these are theorems" as a blocking overclaim under EVD-1/#69.

**How to apply:** the liberal definition (contradiction = any inconsistency,
opposition, OR *discrepancy*) already covers Gödel's gap as a *discrepancy* — so
the universal-contradiction argument survives WITHOUT the false claim that
arithmetic is inconsistent. Say "limit/discrepancy," not "contradiction," for
Gödel; reserve "contradiction" for Russell/Liar.
