# TI-Logic implications-for-mathematics section (book Ch14)

The author wants a STRONG "TI-Logic refutes theorems" claim. The honest way to give it
(architect-approved) is the structure **Building / Refuting / Reframing**:

- **The one unbreakable guardrail:** a valid *conditional* (`if these axioms, then this
  conclusion`) can NEVER be refuted — that is just logical validity. Every strong
  "refutes" sentence must keep this guardrail adjacent, and the refutation must target
  the *unconditional / universalized* form of a claim, NOT the conditional theorem.

- **What may honestly be called REFUTED** (not merely re-scoped):
  1. Any argument resting on a **false dichotomy** — defensible because false dichotomy
     is a recognized fallacy and TI supplies the systematic 3rd/4th truth values.
  2. Any theorem that **essentially requires the unrestricted excluded middle** (e.g.
     non-constructive existence-by-contradiction) — defensible via REAL precedent that
     constructive/intuitionistic math (Brouwer, Heyting, Bishop) already discards exactly
     those proofs. Directly-proved / constructively-valid results lose nothing.

- **What stays "demote universal→local," NOT refutation:** the single global joint
  measure (Fine 1982 / Bell) and definitional realism (NAD-1).

- **Normativity ask:** "GILE values are real" = framework's DEFENDED position (Ch12/19),
  argued to parity with physicalism but SHORT OF A DEDUCTIVE PROOF. Separate it from the
  uncontroversial descriptive half: math already uses value terms (utility / continuity /
  consistency / truth / beauty[Dirac] / reciprocity[game theory]) while professing to be
  value-free.

- **Four-axes ask:** classical logic = one bivalent truth-value; TI asserts 4 Truth-Axes
  (Ch7 canon: PD spectrum real-degree+imag-modality; categorical base-4 MR label; τ/δ
  split; Authority axis) — flagged as defended structural proposal, not a forced theorem.

**Why:** the author repeatedly pushes for sharper/stronger claims; the failure mode is
sliding into "a valid theorem is wrong" or "moral realism is proven." This framing gives
the strong rhetoric the author wants while staying inside EVD-1 / #69 / resonance≠proof.
