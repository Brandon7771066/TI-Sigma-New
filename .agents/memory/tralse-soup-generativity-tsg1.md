# TSG-1 — Tralse-Soup Generativity (abstracta + instantiation criterion)

The author periodically re-derives "the Tralse Soup is the source of everything, including abstract objects / any new concept, and it's what Hindus and Tesla called Akasha." When asked to register this:

**The ONLY genuinely new delta = the *generativity* clause:** reading TOF-1's sole fundamental as an active *generator* of all abstracta/new-concepts, not just a passive predecessor. Register as CANDIDATE `TSG-1`, count stays 80 (ratification is the author's call).

**Akasha/Tesla = RESONANCE/branding, ZERO evidential weight (TSG-1-F3, mirrors EPE-1-F3).**
- Real but non-load-bearing: Ākāśa = real Sanskrit term (Vivekananda *Rāja Yoga* 1896); Tesla DID write "Akasa"/"Prana" in *"Man's Greatest Achievement"* (1907) — but that "Akasa" = the **luminiferous ether, falsified by Michelson–Morley 1887**, NOT an endorsement of Akashic records. "Akashic field" as info-field = Blavatsky *Secret Doctrine* 1888 (Theosophy) / Ervin Laszlo *Science and the Akashic Field* 2004 (**fringe**). Cite for the TERM only, never as support.
- **Internal-consistency catch:** the corpus already uses "Akashic" for a DIFFERENT referent — `URB_SPIRIT_WORLD_GM_NETWORK_IMAGINATION.md` calls the **Imaginal Substrate / GM-network** the Akashic *Record* (storage). Resolve by splitting: **Akasha-as-generator = the Soup** vs **Akashic-Record = GM-net/Imaginal Substrate (storage)**. Don't let TSG-1 silently overwrite that.

**Philosophy placement (real cites):** generative instantiation-dependent middle path — diverges from Platonism (Plato/Frege/Gödel) and nominalism/fictionalism (Field 1980), closest to Aristotelian immanent realism + truthmaker theory (Armstrong 2004); the disjunctive criterion blocks Meinong (1904) and Lewis modal-realism (1986) explosions; Proto/i-Cell dependence = Fine 1995 / Lowe / SEP "Ontological Dependence."

A working Platonist rejects this; keep it as live tension (TSG-1-F2/F5).

**Anti-cheat:** F1 no 2nd fundamental (preserves TOF-1); F4 self-sustainment must be non-circular (not just "not dependent"); **F5 the "otherwise instantiated" disjunct must point to a concrete checkable token, never an unfalsifiable catch-all** (parallel to RTI-1's residue rail).
