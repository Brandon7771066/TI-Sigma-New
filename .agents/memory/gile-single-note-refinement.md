# GILE structure (canonical as of B187, 2026-07-04)

**Rule:** Only **G** is a composite — the **Four C's of Goodness** (Coherence, Concreteness, **Continuity**, Consistency; URB #600). **I, L, E are single notes** scored directly on [0,1] (GSN-1). `G_raw = mean(Four C's)`; `I_raw/L_raw/E_raw = direct single-note score` (NOT mean-of-4).

**Why:** URB #652 originally decomposed *all four* pillars into 4 sub-dims each (16 total). The user ruled that averaging four heterogeneous proxies manufactured false internal structure for what the "one note vs chord" semantics always treated as single values. G is the exception (its four C's are jointly-necessary, qualitatively-distinct facets that emerge with complexity; G is also the only pillar the MR1 gate binds on).

**How to apply:** When operationalizing GILE, score I/L/E as one number each; only G gets the Four-C mean. The old I/L/E sub-descriptors survive only as informal measurement *facets*, never separately averaged. Do NOT re-introduce 16-sub-dim scoring as canonical.
