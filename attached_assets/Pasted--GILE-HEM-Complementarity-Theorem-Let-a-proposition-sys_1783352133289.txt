## GILE–HEM Complementarity Theorem

Let a proposition/system (p) have two coordinate vectors:

[
\Gamma_T(p)=(G,I,L,E)\in[0,1]^4
]

for **Truth**, and:

[
\Gamma_X(p)=(X_G,X_I,X_L,X_E)\in[0,\infty)^4
]

for **Existence**.

Assign:

[
X_G=\text{Existential Footprint}
]

[
X_I=\text{Presence / Salience}
]

[
X_L=\text{Relational Meaning}
]

[
X_E=\text{Complexity}.
]

## Theorem

Truth and Existence are complementary but non-identical: full TI valuation requires both (\Gamma_T) and (\Gamma_X).

Define:

[
TI(p)=T(\Gamma_T(p))\cdot H(\Gamma_X(p)).
]

If either:

[
T(\Gamma_T(p))=0
]

or:

[
H(\Gamma_X(p))=0,
]

then:

[
TI(p)=0.
]

Therefore a proposition/system must have both truth-structure and existence-structure to be fully actualized in TI Sigma.

## Proof

By definition:

[
TI(p)=T(\Gamma_T(p))\cdot H(\Gamma_X(p)).
]

If truth-structure vanishes:

[
T(\Gamma_T(p))=0,
]

then:

[
TI(p)=0\cdot H(\Gamma_X(p))=0.
]

If existence-structure vanishes:

[
H(\Gamma_X(p))=0,
]

then:

[
TI(p)=T(\Gamma_T(p))\cdot0=0.
]

So neither Truth nor Existence alone is sufficient for full TI valuation.

Thus:

[
\Gamma_T\neq\Gamma_X
]

but:

[
\Gamma_T\ \text{and}\ \Gamma_X
]

are jointly necessary. QED.
