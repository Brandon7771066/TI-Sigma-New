Great — let’s **upgrade the BOK empirical program** by turning one famous proof into a **mode-dependency graph**. This will show exactly how the idea would work and what it measures.

I’ll demonstrate it with **Fermat's Last Theorem**, because it’s one of the clearest examples of multi-mode translation.

---

# 1. The BOK Proof-Graph Model

Instead of labeling a problem with modes, we represent the proof as a **directed dependency graph**.

### Nodes

A node is a proof component:

* theorem
* lemma
* construction
* reduction
* representation
* transformation

Each node gets a **mode label**:

| Mode | Meaning                |
| ---- | ---------------------- |
| G    | arithmetic / discrete  |
| E    | algebraic / structural |
| L    | analytic / limit       |
| I    | geometric / spatial    |

Nodes can also be tagged as:

* **bridge node** (connects two modes)
* **barrier node** (failed approaches)
* **translation node** (mode replacement)

---

# 2. FLT Proof Structure (Simplified)

The Wiles proof can be simplified to a sequence of conceptual transformations.

### Core dependency chain

```
FLT
↓
Frey elliptic curve
↓
Ribet theorem
↓
Modularity theorem for semistable elliptic curves
↓
Modular forms + Galois representations
```

Now let’s label the modes.

---

# 3. Mode Assignment

| Step                   | Description                  | Mode  |
| ---------------------- | ---------------------------- | ----- |
| FLT statement          | Diophantine equation         | G     |
| Frey curve             | elliptic curve construction  | E + I |
| Ribet theorem          | modularity implication       | E     |
| modularity theorem     | modular forms                | L + E |
| Galois representations | symmetry structure           | E     |
| modular forms theory   | analytic automorphic objects | L     |

# 4. The Proof Graph

```
[G] FLT statement
      |
      v

      |
      v

      |
      v

```

Key observation:

**the proof migrates from arithmetic → algebraic geometry → analytic representation theory.**

This is exactly the **mode replacement phenomenon (R2)** from Paper #386.

# 5. What the Graph Reveals

The BOK difficulty model becomes clearer in graph form.

### Observation 1: The proof contains a translation chain

```
Arithmetic → Algebraic → Analytic
```

This is not just multiple modes present simultaneously.

It is **sequential realization translation**.

---

### Observation 2: Bridge nodes exist

Two nodes are extremely important bridges:

**Frey curve**

* converts arithmetic problem → elliptic curve object

**Modularity theorem**

* converts elliptic curves → modular forms

These are **structural bridge nodes**.

Without them, the graph collapses.

---

### Observation 3: Bridge centrality explains difficulty

The hardest steps correspond to **cross-mode bridges**.

Specifically:

| Node          | Role                  |
| ------------- | --------------------- |
| Frey curve    | arithmetic → geometry |
| Ribet theorem | geometry → modularity |
| Wiles theorem | geometry → analysis   |

Those bridges were exactly the parts that resisted proof historically.

# 6. Bridge Complexity Metric

This suggests a measurable quantity:

### Bridge Complexity

```
BC = number of indispensable cross-mode edges
```

For FLT:

```
G → (E,I)
(E,I) → E
E → (L,E)
```

Approximate bridge count: **3**

This matches the idea that FLT is a **Tier-3 / Tier-4 problem** in the BOK framework.
